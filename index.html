Cledson Guambe

Programador & Estudante de Informática — Universidade Save

Sou programador e estudante de Informática na Universidade Save (UniSave), movido pela vontade de transformar problemas reais em sistemas que funcionam bem no dia-a-dia. Do meu percurso destaca-se o desenvolvimento de um sistema de controlo de vendas e stock, pensado para acompanhar todo o ciclo comercial — da entrada de mercadoria ao relatório de vendas, num único lugar. Fundei também o Académiku, uma rede académica para estudantes lusófonos, e representei o projecto Xitsundzuxo, um sistema de alerta antecipado de cheias para o Vale do Rio Limpopo, numa jornada científica. Comunico com fluência em português e inglês, o que me permite estudar directamente das fontes internacionais e documentar o meu trabalho para um público mais alargado.

  • Resolução de problemas reais, do esboço no papel ao código em produção
  • Trabalho em equipa, em sistemas com vários perfis de utilizador
  • Comunicação clara, tão útil num relatório técnico como diante de uma turma
  • Fluência em português e inglês, para estudar e documentar sem barreiras

Tecnologias

Cada ferramenta entra numa fase diferente do trabalho — da primeira linha no ecrã até ao dado guardado na base de dados.

  • HTML5 dá o esqueleto a cada página que construo
  • CSS3 veste essa estrutura de cor, espaço e movimento
  • JavaScript dá vida à interface — responde, valida, anima
  • PHP trata da lógica no servidor e fala com a base de dados
  • MySQL guarda e organiza tudo o que precisa de ficar
  • Git regista cada passo do trabalho, sem medo de voltar atrás
  • Java constrói sistemas pensados para durar e crescer
  • Tailwind CSS acelera interfaces consistentes sem sair do HTML
