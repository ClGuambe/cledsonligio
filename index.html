Cledson Guambe

Professor de Informática e Estudante de Licenciatura em Informática

Sou jovem estudante de Licenciatura em Informática na Universidade Save, com uma paixão antiga por explicar as coisas de forma simples, ganha ao longo de anos a ensinar. Concluí a Formação de Professores e Educação de Adultos pelo Instituto Eduardo Chivambo Mondlane e hoje lecciono Informática no Colégio 20 de Julho, em Xai-Xai. Fora da sala de aula, fundei o Académiku, uma rede académica para estudantes lusófonos, e apresentei o projecto Xitsundzuxo, um sistema de alerta antecipado de cheias para o Vale do Rio Limpopo, numa jornada científica.

  • Comunicação clara, treinada todos os dias diante de uma turma
  • Trabalho em equipa, em sistemas com vários perfis de utilizador
  • Raciocínio científico, da investigação até à apresentação pública
  • Vontade constante de aprender uma tecnologia nova

Tecnologias

Cada ferramenta entra numa fase diferente do trabalho — da primeira linha no ecrã até ao dado guardado na base de dados.

  • HTML5 dá o esqueleto a cada página que construo
  • CSS3 veste essa estrutura de cor, espaço e movimento
  • JavaScript dá vida à interface — responde, valida, anima
  • PHP trata da lógica no servidor e fala com a base de dados
  • MySQL guarda e organiza tudo o que precisa de ficar
  • Git regista cada passo do trabalho, sem medo de voltar atrás
  • Java constrói sistemas pensados para durar e crescer
  • Tailwind CSS acelera interfaces consistentes sem sair do HTML
